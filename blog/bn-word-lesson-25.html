MS Word টিউটোরিয়াল পার্ট ২৫ — Track Changes, Comment ও Compare

আমি লিখেছি, বস দেখালেন, আবার হতে পারে আরেক জন — কে কী বদলালো, কখন, কেন — এই সবিরাম প্রক্রিয়ার হিসাব রাখে Track Changes। আর দুজন আলাদা ফাইলে করে দুটো ভার্সন — Compare। পার্ট ২৫-এ দলগত (collaborative) এডিটিং শিখব।

১. Track Changes চালু

Review ট্যাব → Track Changes (Ctrl+Shift+E)। চালু থাকলে আপনার প্রতিটা পরিবর্তন রঙিন মার্কিংয়ের সাথে রেকর্ড হয়: যোগ (আন্ডারলাইন+রঙ), ডিলিট (স্ট্রাইকথ্রু)।

  • Tracking চালু/বন্ধ: Ctrl+Shift+E
  • Markup অবস্থা: All Markup / Simple Markup / No Markup
  • Simple Markup — ডান মার্জিনে বারে পরে মন্তব্য

২. Accept / Reject

মার্কিংগুলো দেখে সিদ্ধান্ত: Review → সাথে Previous/Next ঘুরে —

  1. প্রতিটা পরিবর্তনে গিয়ে Accept বা Reject
  2. সব মেনে নিতে: Accept → Accept All
  3. সব ফেলে দিতে: Reject → Reject All

৩. Comment — মন্তব্য

পরিবর্তন না করে ব্যাখ্যা/প্রশ্ন করতে নির্বাচনে ডান-ক্লিক → New Comment (Ctrl+Alt+M)। Comment উইন্ডোতে Reply, Resolve (সমাধান), Delete। মার্জিন বারে কমেন্টগুলোর ধারাবাহিকতা পরিষ্কার দেখা যায়।

৪. Compare Documents — দুই ফাইল মেলানো

দুজন আলাদা ফাইলে এডিট করেছে — মার্জ করতে: Review → Compare → Compare… → Original আর Revised ফাইল বাছুন → OK। Word নতুন এক ফাইলে দুইয়ের পার্থক্যগুলো মার্ক করে দেখাবে।

  1. Review > Compare > Compare
  2. Original document (পুরনো) ও Revised document (নতুন) বাছুন
  3. Label changes with: লেখক (ঐচ্ছিক)
  4. পার্থক্যগুলো মার্কিং সহ নতুন ডকুমেন্ট

জটিল হলে Combine (একই বেস-ফাইলে দুজন ব্যক্তি) ব্যবহার করুন।

৫. Rules ও Settings

Review → Tracking-এর ছোট তীর → Track Changes Options — মার্কিং রঙ, সাইট (বলো ইন ফুটার ইত্যাদি) কাস্টমাইজ। Change User Name-এ আপনার নাম দিন — Track-এ রিভিউয়ার হিসেবে দেখা যাবে।

টুলকাজ
Accept/Rejectচূড়ান্ত সিদ্ধান্ত
Commentব্যাখ্যা/আলোচনা
Compare২ ফাইল পার্থক্য
Combine২ ফাইল মার্জ

৬. ফাইনালাইজ

সব Accept এর পর মার্কিংগুলোই আর দরকার নেই। বাট কখনো কখনো আপনাকে শুধু "অনুমোদিত" কপি পাঠাতে হবে — সেক্ষেত্রে Accept All করেই সেভ করুন। Track বন্ধ করাই মনে রাখা গুরুত্বপূর্ণ।

প্রফেশনাল টিপ: চিঠি/রিপোর্ট জমা দেওয়ার আগে Review → Spellingকেও একবার — আর Track Changes-এর অবস্থা অবশ্যই বন্ধ আছে কিনা দেখুন, নইলে মার্কিংসহ পাঠিয়ে ফেলবেন।

প্র্যাকটিস

একটা ফাইল-কপি নিয়ে Track চালু করে ৩-৪টা Edit করুন, comment দিন, Accept/Reject দেখুন, তারপর মূলটার সাথে Compare করুন। পরের পার্ট: নিরাপত্তা — পার্ট ২৬ পড়ুন।

চূড়ান্ত জিনিসটা আপনার জন্য সেভ রাখা হলো — লোভ না দেখিয়ে নয়! এই সিরিজের শেষ পার্টে (পার্ট ৩০) একদম সহজ ধাপে শিখবেন কীভাবে MS Office 2016, 2019, 2024 ও Microsoft 365-এর অ্যাক্টিভেশন ও লাইফটাইম সিস্টেম নিজের পিসিতে সেট আপ করতে হয়। সব পোস্টের রাজার হীরকটা এখানেই! পার্ট ৩০ দেখুন →

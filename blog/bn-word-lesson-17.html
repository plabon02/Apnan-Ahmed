MS Word টিউটোরিয়াল পার্ট ১৭ — Theme, Watermark, Page Border ও Page Color

ডকুমেন্টের চেহারা একবারে বদলে দিতে Design ট্যাবের চারটা পাওয়ার টুল: Theme, Watermark, Page Border আর Page Color। পার্ট ১৭-এ এগুলো দিয়ে ডকুমেন্টকে পেশাদার লুক দেব।

১. Theme — ডকুমেন্টের রঙ-ফন্ট প্যাকেজ

Design ট্যাবের Themes — এক ক্লিকে পুরো ডকুমেন্টের কালার, ফন্ট আর ইফেক্ট বদলে দেয়। পাশেই Color/Fonts ড্রপডাউন (Customize Colors) দিয়ে নিজের ব্র্যান্ড-কালার (যেমন আপনার পিঙ্ক) সেট করতে পারবেন।

২. Document Formatting — স্টাইল সেট সোয়াপ

Design ট্যাবের Document Formatting গ্যালারি — স্টাইল সেট (পার্ট ১৬-এর হেডিং-এর লুক) এক ক্লিকে বদলায়। ডিফল্ট রঙের লাইনগুলোয় ক্লিক করলে চেঞ্জ হবে।

৩. Watermark — ওয়াটারমার্ক

Design → Watermark — কনফিডেনশিয়াল, ড্রাফট, URGENT ইত্যাদি রেডিমেড আছে। নিজের লিখতে: নিচে Custom Watermark → Text Watermark → লেখা, ফন্ট, সাইজ, রঙ দিন (Diagonal/Horizontal)। অথবা ছবির ওয়াটারমার্ক। সরাতে Custom Watermark → No watermark।

  1. টেক্সট: আপনার নাম/লোগো টেক্সট
  2. ছবি: লোগোর পিএনজি (ট্রান্সপারেন্ট) — Washout টিক রাখুন
  3. Limit: ওয়াটারমার্ক সব পেজে দেখা যায়

৪. Page Color — পেজের রঙ

Design → Page Color — কল শুধু ওয়েব/স্ক্রিন দেখার জন্যই; প্রিন্ট হলে কালি খরচ হবে। হালকা ক্রিম/প্যাস্টেল রঙ পড়তে আরামদায়ক। Print Background (File → Options → Display) না করলে প্রিন্টে আসবে না।

৫. Page Border — পেজের চারপাশের ফ্রেম

Design → Page Borders → Borders/Shading ডায়ালগে Page Border ট্যাব।

অপশনব্যবহার
Box/Shadowসাধারণ ফ্রেম
Artডিজাইন-ভর্তি সীমানা (ফল, তারা ইত্যাদি)
Apply toWhole document / This section / First page only

আর্ট বর্ডার সার্টিফিকেট/শুভেচ্ছা কার্ডে মজা, তবে প্রফেশনাল রিপোর্টে হালকা Box-ই ভালো।

৬. সব মিলিয়ে এক লুক

একটা ডকুমেন্টে এই চারটার ব্যবহার সাবধানে করুন — Theme+Formatting ধরুন, অতিরিক্ত Page Color/Border লাগে না। রিপোর্টে থাকুক: হালকা হেডার, আপনার লোগোর ছোট ওয়াটারমার্ক, পাতলা বর্ডার।

পরিমিতিই আসল: ওয়াটারমার্ক অতিরিক্ত রাখলে পাঠ্যবিরোধী লাগে — ৯০% পেজে একাধিক জিনিস নয়, আলাদা করে এগুলোর ব্যবহার বুঝে নিন।

প্র্যাকটিস

আপনার নামের একটা Watermark দিন, হালকা Page Color দিন, তারপর সার্টিফিকেটের জন্য Art Border ট্রাই করুন। পরের পার্ট — Table of Contents: পার্ট ১৮ পড়ুন।

বাংলা Excel আগস্ট 2026

Excel-এ কি-বোর্ড শর্টকাটে কাজ দ্বিগুণ গতিতে — ১০টা চমৎকার শর্টকাট

১৮ বছর ধরে Microsoft Office-এর সাথে কাজ করছি। এই সময়ে সবচেয়ে বড় শিক্ষা — কাজের গতি আসে মাউস নয়, কি-বোর্ড থেকে। বলা যায়, যদি একটা জিনিসই শিখতে চান সেই দিন, সেটা এই শর্টকাটগুলো।

নিচে এমন ১০টা শর্টকাট দিচ্ছি যা প্রতিদিন সবাইকেই লাগে। প্রতিটার সাথে আছে ছোট্ট একটা ব্যবহারিক উদাহরণ।

১. Ctrl + Shift + L — ফিল্টার চালু/বন্ধ

বড় টেবিলে ফিল্টার লাগানোর জন্য মাউস দিয়ে মেনুতে যাওয়ার চেয়ে এই শর্টকাট ৩ সেকেন্ড বাঁচায়। কার্সর ডাটা-র ভেতরে রেখে কী দুটো চাপলেই ফিল্টার চলে আসবে, আবার চাপলে উঠে যাবে।

২. Ctrl + T — টেবিলে রূপান্তর

ডাটার যেকোনো ঘরে থেকে Ctrl + T চাপুন — Excel নিজে থেকে সাজানো, রঙিন টেবিল বানিয়ে দেয় + ফিল্টারও যোগ করে। রিপোর্ট বানাতে ঘণ্টা খরচ করার দরকার নেই।

৩. Alt + = — স্বয়ংক্রিয় SUM

এর থেকে দ্রুত যোগফলের কোনো উপায় নেই। সংখ্যার নিচের ঘরে গিয়ে Alt + = চাপুন — Excel নিজেই রেঞ্জ ধরে নিয়ে যোগ করে দেবে।

৪. Ctrl + ; — আজকের তারিখ

ম্যানুয়ালি তারিখ টাইপ না করে এখনকার তারিখ বসাতে Ctrl + ; (সেমিকোলন) চাপুন। ফাইল সেভ-এর তারিখ, হেডার, ইনভয়েস — সব জায়গায় কাজে লাগে।

৫. Ctrl + Arrow Keys — রেঞ্জের শেষ প্রান্তে যাওয়া

৩ হাজার লাইনের ফাইলে শেষ ঘরে যেতে মাউসে স্ক্রল করার দরকার নেই — Ctrl + ↓ এক চাপেই নিচের শেষ ঘরে পৌঁছে যাবেন। Ctrl + Shift + Arrow দিলে পুরো রেঞ্জ সিলেক্টও হয়ে যায়।

৬. F4 — শেষ কাজ আবার করা

সেল কালার দেওয়া, সারি মুছা, ফরম্যাট — যা-ই শেষ করেছেন, F4 চাপলেই সেটা আবার হবে। অনেকগুলো সেল একসাথে সাজাতে এই একটা কী বিস্ময়কর কাজ করে।

৭. Ctrl + D / Ctrl + R — উপরের/বামের মান কপি

উপরের ঘরের মানটা নিচের ঘরে কপি করতে Ctrl + D, বামেরটা ডানে কপি করতে Ctrl + R। ফর্মুলা টেনে নামানোর ঝামেলা এতে অনেকটাই কমে যায়।

৮. Ctrl + Shift + $ — মুদ্রা ফরম্যাট

সংখ্যাকে টাকার ($) ফরম্যাটে দিতে মেনু খুঁজতে হবে না — Ctrl + Shift + $ এক চাপেই। সাথে %-এর জন্য Ctrl + Shift + % কথাও মনে রাখবেন।

৯. Ctrl + 1 — ফরম্যাট সেল ডায়ালগ

ডেটা, নম্বর, বর্ডার, অ্যালাইনমেন্ট — সব ফরম্যাট এক ডায়ালগে। রাইট-ক্লিক করে Format Cells খোঁজার দিন শেষ।

১০. Ctrl + PgUp / PgDn — শিট বদলানো

একাধিক শিটের ফাইলে নিচের ট্যাবে ক্লিক না করে Ctrl + PgDn দিয়ে সামনের শিট, Ctrl + PgUp দিয়ে পেছনের শিটে যান। ফাস্ট আর ক্লিন।

এই শর্টকাটগুলোও চেষ্টা করে দেখুন: Ctrl + Space (পুরো কলাম সিলেক্ট), Shift + Space (পুরো সারি), Ctrl + Shift + + (নতুন সারি/কলাম যোগ)।

আপনি কোন শর্টকাটটা সবচেয়ে বেশি ব্যবহার করেন? কমেন্টে জানান — পরের পোস্টে ওই ধারণা দিয়েই Excel-এর আরেক গভীর টপিক নিয়ে আসবো।

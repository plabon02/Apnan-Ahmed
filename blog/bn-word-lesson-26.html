বাংলা Word আগস্ট 2026

MS Word টিউটোরিয়াল পার্ট ২৬ — পাসওয়ার্ড প্রোটেকশন ও Restrict Editing

গোপন রিপোর্ট, স্যালারি শিট অথবা বিক্ষোভের আগে অনুমোদন চাওয়া ফর্ম — এমন জিনিস শুধু যাকে চান তাকেই দেখানোর ব্যবস্থা দরকার। পার্ট ২৬-এ Word-এর নিরাপত্তা ফিচার: পাসওয়ার্ড প্রোটেকশন, Restrict Editing ও Mark as Final।

১. পাসওয়ার্ড — ডকুমেন্ট এনক্রিপ্ট

File → Info → Protect Document → Encrypt with Password → শক্তিশালী পাসওয়ার্ড দিন (২ বার)। এবার ফাইল খুলতে পাসওয়ার্ড লাগবে।

  1. File > Info > Protect Document
  2. Encrypt with Password → পাসওয়ার্ড — OK
  3. খোলার সময় পাসওয়ার্ড চাইবে
সাবধান! পাসওয়ার্ড ভুলে গেলে ফাইল আর খুলতে পারবেন না — কোনো recovery নেই। তাই পাসওয়ার্ড নিরাপদ জায়গায় লিখে রাখুন।

২. পাসওয়ার্ড সরানো

File → Info → Protect Document → Encrypt with Password → ফাঁকা রেখে OK — পাসওয়ার্ড মুছে যাবে। এছাড়া Save As → Tools → General Options → Password to open / Password to modify — একেএকে দুই স্তরের নিরাপত্তা।

৩. Restrict Editing — কোন অংশ এডিটযোগ্য

শুধু পাসওয়ার্ডই নয়, কারা কতটুকু বদলাবে সেটাও নিয়ন্ত্রণ: Review → Restrict Editing (ডানে প্যান খুলবে) →

  • Formatting restrictions — ফন্ট/স্টাইল বদল বন্ধ
  • Editing restrictions → Read only / Comments / Filling in forms
  • Comments all: সবাই কমেন্ট করতে পারবে
  • Forms: ফর্ম-ফিল্ডেই কেবল লেখা যাবে

সেকশন-ভিত্তিকও করা যায়: সেকশন সিলেক্ট → Exceptions দিয়ে ওই অংশ মুক্ত। Start Enforcing Protection → পাসওয়ার্ড/নথি কী।

৪. Mark as Final — পাঠানের সিলমোহর

ফাইল "ফাইনাল" ঘোষণা করতে Protect → Mark as Final — পাঠকের পড়ার মোড খোলে, এডিট বন্ধ থাকে (এটিও কিন্তু শুরু-সম্পাদনার সীমা নয় — সহজে Remove Mark as Final হয়)। জেনে রাখা ভালো।

৫. Read-only Save ও ফর্ম

উপায়ব্যবহার
Save As → Read-only recommendedসাধারণ সংখ্যালঘু সুরক্ষা
Restrict Editing → Filling in formsজরিপ/অনুবেদন ফর্ম
Digital Signature (PKI)আইনি নথি — যাদের সার্টিফিকেট আছে

৬. শেয়ার করা নিরাপদে

নিরাপদ শেয়ারের জন্য: PDF এক্সপোর্ট করেও পাসওয়ার্ড দেওয়া যায় (পার্ট ২৭)। এছাড়া OneDrive-এ Share → Link + password/expiry — Cloud-based সুরক্ষা। পুরনো পাসওয়ার্ডযুক্ত ফাইল আপডেটের সময় খেয়াল রাখবেন।

মনে রাখবেন: Encrypt with Password-এর চেয়ে কাছে আসার আর কিছু নেই — সবাই এটা পারবে না। কিন্তু রিকভারির সুযোগও নেই। لذا পাসওয়ার্ড ম্যানেজার ব্যবহার করুন।

প্র্যাকটিস

একটা ফাইল Encrypt with Password করুন, আবার Remove করুন, Restrict Editing → Read only দিয়ে Enforce করুন, তারপর Mark as Final দেখুন। পরের পার্ট: PDF এক্সপোর্ট — পার্ট ২৭ পড়ুন।

চূড়ান্ত জিনিসটা আপনার জন্য সেভ রাখা হলো — লোভ না দেখিয়ে নয়! এই সিরিজের শেষ পার্টে (পার্ট ৩০) একদম সহজ ধাপে শিখবেন কীভাবে MS Office 2016, 2019, 2024 ও Microsoft 365-এর অ্যাক্টিভেশন ও লাইফটাইম সিস্টেম নিজের পিসিতে সেট আপ করতে হয়। সব পোস্টের রাজার হীরকটা এখানেই! পার্ট ৩০ দেখুন →

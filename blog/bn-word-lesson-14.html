বাংলা Word আগস্ট 2026

MS Word টিউটোরিয়াল পার্ট ১৪ — Chart ও গ্রাফ তৈরি

সংখ্যার গল্পটা চোখে দেখাতে চার্ট-ই সর্বোত্তম। Word-এ টেবিলের পাশাপাশি সামান্য ডেটা টাইপ করেই Bar, Pie, Line চার্ট বানানো যায়। আজকের পার্ট ১৪-এ সেটাই করব।

১. Chart ইনসার্ট

Insert → Chart → Chart Type চয়ন (Column, Line, Pie, Bar, Area) → OK। সাথে সাথে Excel-এর মতো ছোট একটা ডেটা উইন্ডো খুলে — সেখানে সংখ্যা বসান চার্ট আপডেট হবে।

  1. শ্রেণির নাম (মাস/বিষয়) আর মান (সংখ্যা) লিখুন
  2. ডেটা উইন্ডো বন্ধ করুন (বর্ডারের X)
  3. চার্ট ডকুমেন্টে দেখা যাবে

২. Chart Type ও ডেটা এডিট

চার্ট সিলেক্ট করলে ট্যাব দুটি খোলে: Chart Design ও Format।

  • Chart Design → Edit Data — আবার ডেটা উইন্ডো খুলবে
  • Chart Design → Change Chart Type — Bar টা Pie-তে বদলে দিন
  • Delete/Add Category: Edit Data-তে নতুন রো/কলাম দিন

৩. টাইটেল, লেজেন্ড ও ডেটা লেবেল

এলিমেন্টকীভাবে
Chart TitleChart Design → Add Chart Element → Chart Title
Data LabelsAdd Chart Element → Data Labels → Outside/Inside
Legendনিচে/ডানে রাখতে Legend
Axis TitlesAdd Chart Element → Axis Titles

৪. Chart Style ও কালার

Chart Design-এর Chart Styles গ্যালারি — এক ক্লিকে ডিজাইন বদলে যায়। ফন্ট/কালার আরও নিখুঁতভাবে বদলাতে লেখা/বারের উপর রাইট-ক্লিক → Format Data Series। হালকা ও বর্ণ-সৃজনশীল (...) রং বাছুন — প্রিন্ট ও স্ক্রিন দুটোর জন্যই যথাযথ।

৫. Excel-এর সাথে লিংক

বড় চার্ট Excel থেকে আনতে: Excel এ তৈরি চার্ট কপি (Ctrl+C) → Word-এ পেস্ট (Ctrl+V) → Paste Options-এ Linked Chart বাছুন। Excel-এ ডেটা বদলালে Word-এ আপডেট হবে। (Word এ ঢোকানো ছোট ডেটা চাইলে Excel Spreadsheet Template-ও আছে — Insert → Table → Excel Spreadsheet)

৬. চার্টের যত্ন

চার্টে অতিকথন নয় — শিরোনাম + ডেটা লেবেলই যথেষ্ট। ছড় যেমন ছোট মানের জন্য Pie, সময়ধারা/প্রবণতার জন্য Line, তুলনার জন্য Column। চার্টের পাশে বিশ্লেষণ ১-২ লাইনে বিস্তারিত দিন।

ভুলে যাবেন না: চার্ট মানেই সংখ্যার সঠিকতা। ডেটা উইন্ডোয় আপনার সংখ্যা ঠিক আছে কিনা — সেটাই আসল চার্টের সৌন্দর্য।

প্র্যাকটিস

একটা Column Chart বানিয়ে ৬ মাসের বিক্রি দিন, Title + Data Labels যোগ করুন, তারপর Pie-তে বদলে দেখুন কী হয়। পূর্ববর্তী পার্টগুলো ভালো লাগলে পরের পার্ট: Find & Replace — পার্ট ১৫ পড়ুন।

চূড়ান্ত জিনিসটা আপনার জন্য সেভ রাখা হলো — লোভ না দেখিয়ে নয়! এই সিরিজের শেষ পার্টে (পার্ট ৩০) একদম সহজ ধাপে শিখবেন কীভাবে MS Office 2016, 2019, 2024 ও Microsoft 365-এর অ্যাক্টিভেশন ও লাইফটাইম সিস্টেম নিজের পিসিতে সেট আপ করতে হয়। সব পোস্টের রাজার হীরকটা এখানেই! পার্ট ৩০ দেখুন →

বাংলা Word আগস্ট 2026

MS Word টিউটোরিয়াল পার্ট ২৭ — PDF এক্সপোর্ট, প্রিন্ট ও শেয়ার

লেখা শেষ, এখন তা জমা দিতে হবে — প্রিন্ট বা PDF। আজকের পার্ট ২৭-এ শিখব কীভাবে একদম পেশাদারভাবে ডকুমেন্টকে PDF-এ এক্সপোর্ট করা হয় এবং প্রিন্টের সব সেটিং সঠিক করা যায়।

১. Save As PDF — এক ক্লিক

File → Save As → Save as type: PDF → Save। 10 সেকেন্ডে রেডি। PDF তে ফন্ট, লেআউট সব কিছুর হুবহু ছাপ — যেকোনো ডিভাইসে এক রকম দেখাবে।

  • ছবির গুণমান কমাতে কিনা — Export-এ Optimize for: Minimum size
  • ফন্ট এমবেড: Word স্বয়ংক্রিয় প্রয়োজনীয় ফন্ট সহ ছাপে
  • হাইপারলিংক/Bookmark PDF-এ কাজ করে

২. PDF/A — আর্কাইভ ফরম্যাট

দীর্ঘমেয়াদী সংরক্ষণে (অফিসিয়াল/আর্কাইভ) PDF/A স্ট্যান্ডার্ড। Save As → PDF → Options → PDF/A compliant টিক। এটা ভবিষ্যতের যেকোনো PDF রিডারে বিশ্বস্তভাবে খুলবে।

৩. প্রিন্ট সেটআপ

প্রিন্টের আগে: File → Print (Ctrl+P) — ডানদিকে লাইভ প্রিভিউ।

৪. প্রিন্ট প্রিভিউয়ের পর চূড়ান্তকরণ

প্রিন্টের উদাহরণ: দুই পেজ এক সাথে দেখতে Zoom কমান; মার্জিনে ফাঁক হিসেবে কাগজ অপচয় দেখলে Page Setup-এ Scale to Fit। Print on both sides প্রিন্টার সাপোর্ট করলে — ফ্লিপঅনলং এজ।

৫. Microsoft Print to PDF — ভার্চুয়াল প্রিন্টার

Windows-এ বিল্ট-ইন Microsoft Print to PDF প্রিন্টার দিয়ে যেকোনো ডকুমেন্ট PDF: Ctrl+P → printer = Microsoft Print to PDF → Print। তখনও PDF পাবেন, কিন্তু Save As PDF-এর চেয়ে ফাইলের সাইজ একটু ভিন্ন হতে পারে।

৬. শেয়ার করা

ইমেইল/ওয়েব শেয়ারে PDF-ই সেরা ফরম্যাট — এডিট-রক্ষা আর ব্র্যান্ড-ধারাবাহিক রাখে। ডকুমেন্ট এডিট করার অধিকার সীমিত করতে শুধু PDF পাঠান, source-ফাইলটাকে সাথে দিলে তাতে পার্মিশনও ঝুঁকছে।

চূড়ান্ত টিপ: PDF বানিয়ে নেওয়ার আগে সর্বদা TOC/Field আপডেট + Track Changes বন্ধ + বানান চেক — যাতে পাঠকের সামনে সব clean থাকে।

প্র্যাকটিস

একটা ডকুমেন্ট Save As PDF করুন, এক পাতা প্রিন্ট প্রিভিউ দেখুন, PDF/A অপশনটা একবার ক্লিক করে File সাইজ তুলনা করুন। পরের পার্ট: AutoSave, রিকভারি ও ভার্সন: পার্ট ২৮ পড়ুন।

চূড়ান্ত জিনিসটা আপনার জন্য সেভ রাখা হলো — লোভ না দেখিয়ে নয়! এই সিরিজের শেষ পার্টে (পার্ট ৩০) একদম সহজ ধাপে শিখবেন কীভাবে MS Office 2016, 2019, 2024 ও Microsoft 365-এর অ্যাক্টিভেশন ও লাইফটাইম সিস্টেম নিজের পিসিতে সেট আপ করতে হয়। সব পোস্টের রাজার হীরকটা এখানেই! পার্ট ৩০ দেখুন →
